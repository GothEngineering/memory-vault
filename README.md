# Memory Vault
A database project i made on Godot using the SQLite plugin. Its purpose was to practice the fundamentals of a database because it's my first ever made while also doing a passion app of mine to allow for memory tracking to not forget events from my childhood.

<img width="1152" height="649" alt="databaseshowcase" src="https://github.com/user-attachments/assets/0e02c5c1-0608-493a-8a00-186a9962ffb9" />

# Features

CRUD functionality: Create data, read data, update data and delete data.

Basic pagination: Next page, previous page, sort by, basic search bar with the title input

Accessibility: It's very lightweight :)
